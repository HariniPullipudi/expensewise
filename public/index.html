Comprehensive Architecture

Built for Real-World Personal Finance

Everything you need to demonstrate a comprehensive Full Stack Development project.

Interactive Chart.js Visuals

Four dynamic charts calculated from actual database aggregations: category doughnuts, 6-month comparisons, spending trends, and category rankings.

Category Budgets & Alerts

Set monthly spending limits for each category. Dynamic progress bars warn you at 80% usage and alert when budgets are exceeded.

CSV Export & Print Reports

Export filtered transaction records with spreadsheet formula injection protection. Features a clean browser print layout for physical reports.

Multi-Tenant Security

Bcrypt password hashing, express-session cookie authentication, CSRF tokens, rate limiters, and strict ownership validation on all routes.

Native INR (₹) Formatting

Display currency numbers in standard Indian format (e.g. ₹25,000.00) while storing values cleanly as numbers in MongoDB.

Fully Responsive Design

Adaptive CSS Grid and Flexbox layout that renders seamlessly across desktop screens, laptops, tablets, and smartphones.

Full Stack Technology Architecture
